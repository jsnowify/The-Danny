## How the current application works

**State and flow.** src/store.ts:15 defines eight typed phases; continued exploration returns to explore. Zustand owns inventory, hanging queues, preferences and discrete UI state. src/scene/runtime.ts:2 holds movement, input and atmosphere outside React. App lazy-loads the 3D scene and audio is imported only after the title gesture. Scene readiness is set in Forest's effect, but App currently mounts HUD before it.

**World, chunking and instancing.** Seed 4217 creates a 200 × 200 world. src/scene/world.ts:42 assigns instances to 25-unit chunks and reserves the clearing, path, pond and memory positions. Flora repacks visible chunks when the traveler crosses a 12.5-unit boundary or changes tier, using a 76-unit chunk-center radius. Eleven kind batches and two canopy outline batches share geometries and one wind material. Grass scales toward zero at distance in the vertex shader. CollisionGrid uses 8-unit spatial cells and circular obstacles. There are generic pine and faceted crown trees; species LOD sets do not exist.

**Quality.** High: 1024 shadows, bloom/vignette, full grass, 480 dust instances, max DPR 1.75. Medium: 512 shadows, vignette, 60% grass, 260 dust, max DPR 1.4; coarse-pointer devices start here. Low: no shadows/composer, 30% grass, 120 dust, DPR 1. A fullscreen grain shader still draws at Low. Butterflies/fireflies and birds retain fixed counts. Drei PerformanceMonitor adapts Auto; manual quality is respected.

**Audio.** TitleScreen creates/resumes an AudioContext in the original gesture, then imports Tone. A singleton owns music/nature/effects buses, master gain and limiter; bridge.ts dispatches effects. Music is an original seeded D-pentatonic arrangement at 54 BPM with default 4/4 meter, pad, FM plucks and bass. Hung progress increases arrangement and viewer ducks it. Nature synthesizes pink-noise wind, brown-noise water, generic bird chirps, dusk insects and proximity chimes. Hidden tabs suspend the context. Pause only pauses transport; continuous wind remains audible.

**Viewer and inventory.** The DOM viewer uses a dialog focus trap, Escape, blurred backdrop, tilted generated polaroid and paragraph fades. Optional photos cover-fit and fall back on errors. Keep saves immediately and animates a cloned picture toward the inventory before it is removed; a store subscription triggers the traveler's hop. Slots reread kept/hung pictures. Dialog cleanup returns to the prior focused element, which is not always the canvas.

**Hanging and tree.** Timeline sequences each carried ID for 2.25 seconds, lands it at 1.65 seconds and saves each landing. Eight stable anchors drive the eased arc. Pre-positioned instance groups grow leaves, blossoms and ground flowers. Picture strings are plain cylinders. All eight lands trigger finale; the camera orbits, music swells, the tribute appears and Keep exploring returns to explore.

**Persistence.** The existing implementation already uses the-danny-v2, schema 2. When absent, a valid v1 envelope is normalized and copied immediately, preserving IDs, all six current preferences and introSeen; the v1 backup stays until confirmed reset. Existing v2 takes precedence, including an empty reset. Hung IDs are unioned into collected IDs. Storage exceptions fall back to session memory; identical writes are suppressed. No migration rewrite or new key is needed. Language, species discovery and independent mix settings do not exist yet.

## Immutable 60-second baseline

Sequential isolated Chromium pages, local Vite at 127.0.0.1:5174, empty central clearing, skip intro, muted synthesized audio, reduced motion off, manual quality, 960 × 640 CSS pixels, device scale 1. Whole-frame counters include shadows and postprocessing. The first four seconds warm up; remaining frames contribute to rounded call/triangle means and rendered-frame FPS. CDP Runtime.getHeapUsage is read immediately after the 60-second timer; no forced GC. Timer completion can exceed 60 seconds on the software renderer.
