## Before / after performance

Unforced-GC heap snapshots do not establish a memory improvement or a leak. Resource counts are not GPU byte measurements.

## Migration and preview safety

`the-danny-v2`, schema 2, is the current save. If it is absent, a valid v1 envelope is normalized and immediately copied, preserving known collected/hung IDs, six preferences and introSeen. Hung IDs remain in collected. The original v1 backup stays untouched until a confirmed real reset. Existing v2 wins, including an empty reset, so old progress cannot reappear. Unknown IDs and invalid values are filtered; storage restrictions retain the current session. Migration already existed before this stage and has been regression-tested rather than replaced.

Preview captures actual collected/hung/intro and temporary UI state once, then displays the first N stable memories as collected and hung. Persisted progress comes from that backup while the preview is active. Restore returns the actual progress; reload also restores it. Changed preferences continue to save. The cream development ring follows the store radius without subscribing React renders to animation. The debug Reset button deliberately clears real progress without the pause menu's confirmation; use Restore when inspecting an existing save. Normal player reset retains its confirmation and preferences and removes the legacy backup.
